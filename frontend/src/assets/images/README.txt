Drop real images here (webp recommended; png, jpg, jpeg or avif also work):

  portrait.webp        -> hero portrait (about 960 px wide is plenty)
  manish-poetry.webp   -> Manish Poetry project preview (about 1440 px wide)

They are picked up automatically; until then the site shows labelled placeholders.
Keep only one file per name, and resize/convert large photos to WebP first:
a 2 MB PNG makes the site slow to load on phones.
